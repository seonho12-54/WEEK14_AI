# 1장 대규모 언어 모델 이해하기

## 0. 이 장의 핵심 한 줄

**LLM은 대량의 텍스트로 다음 토큰을 예측하도록 학습한 트랜스포머 기반 신경망이며, 사전 학습과 미세 조정을 거쳐 다양한 언어 작업을 수행한다.**

---

## 1. 1장에서 잡아야 할 큰 그림

1장은 코드를 바로 구현하는 장이라기보다, 앞으로 만들 mini GPT가 어떤 구조와 학습 흐름을 가지는지 알려주는 지도 역할을 한다.

이 장에서 반드시 잡아야 하는 흐름은 다음과 같다.

```text
텍스트 데이터
-> 토큰화
-> 다음 토큰 예측으로 사전 학습
-> GPT 구조 학습
-> 필요하면 미세 조정
-> 특정 작업 수행
```

우리 과제로 바꾸면 다음 흐름이다.

```text
NSMC 영화 리뷰 텍스트
-> 직접 구현한 BPE tokenizer
-> GPTDataset
-> Embedding
-> Causal Multi-Head Attention
-> GPTModel
-> 사전 학습
-> 감성 분류 미세 조정
```

## 2. LLM이란 무엇인가

LLM은 Large Language Model의 약자이며, 한국어로는 대규모 언어 모델이다.

여기서 **대규모**는 두 가지를 뜻한다.

| 의미 | 설명 |
| --- | --- |
| 큰 모델 | 매우 많은 파라미터를 가진 신경망 |
| 큰 데이터 | 매우 많은 텍스트 데이터로 학습 |

LLM은 문장을 이해하는 것처럼 보이고, 질문에 답하고, 글을 쓰고, 요약하고, 번역하고, 코드를 작성할 수 있다.

하지만 내부적으로는 마법처럼 의미를 바로 읽는 것이 아니라, **현재까지의 토큰들을 보고 다음 토큰이 무엇일지 예측하는 방식**으로 학습된다.

### 꼭 암기

**LLM의 핵심 학습 목표는 다음 토큰 예측(next-token prediction)이다.**

```text
입력: 오늘 날씨가
정답: 좋다
```

이런 단순한 문제를 엄청나게 많은 텍스트에서 반복하면, 모델은 문법, 문맥, 표현, 지식의 패턴을 배운다.

---

## 3. 기존 머신러닝과 LLM의 차이

전통적인 머신러닝에서는 사람이 특징을 직접 설계하는 경우가 많았다.

예를 들어 스팸 메일 분류를 한다면 사람이 이런 특징을 만들 수 있다.

```text
무료라는 단어가 있는가?
느낌표가 많은가?
수상한 링크가 있는가?
대문자가 많은가?
```

반면 딥러닝과 LLM은 원본 데이터를 넣고, 모델이 내부 표현을 스스로 학습한다.

| 구분 | 전통적 머신러닝 | LLM |
| --- | --- | --- |
| 특징 추출 | 사람이 직접 설계 | 모델이 학습 |
| 입력 | 사람이 만든 feature | token ID와 embedding |
| 강점 | 단순 작업, 작은 데이터 | 복잡한 언어 이해와 생성 |
| 한계 | 규칙 밖 상황에 약함 | 많은 데이터와 연산 필요 |

### 꼭 암기

**LLM은 사람이 feature를 직접 뽑는 대신, 대량의 데이터에서 표현을 스스로 학습한다.**

---

## 4. LLM 애플리케이션

LLM은 자연어를 입출력으로 사용하는 다양한 작업에 쓰인다.

대표적인 예:

| 작업 | 예시 |
| --- | --- |
| 질의응답 | 사용자의 질문에 답변 |
| 요약 | 긴 글을 짧게 정리 |
| 번역 | 한국어를 영어로 번역 |
| 글쓰기 | 이메일, 보고서, 소설 작성 |
| 코드 작성 | 함수 구현, 오류 설명 |
| 분류 | 리뷰 긍정/부정, 스팸 분류 |
| 챗봇 | 대화형 AI 서비스 |

우리 과제에서는 이 중 두 가지 흐름을 직접 경험한다.

```text
1. 사전 학습: 다음 토큰 예측
2. 미세 조정: 영화 리뷰 긍정/부정 분류
```

---

## 5. LLM의 구축 단계

LLM은 보통 한 번에 완성되지 않는다.

큰 흐름은 두 단계다.

```text
1단계: 사전 학습(pretraining)
2단계: 미세 조정(fine-tuning)
```

### 5.1 사전 학습

사전 학습은 레이블이 없는 대량의 텍스트로 모델을 훈련하는 단계다.

정답 라벨을 사람이 붙이지 않아도 된다. 문장 자체에서 다음 토큰을 정답으로 만들 수 있기 때문이다.

예:

```text
입력: 이 영화는 정말
정답: 좋았다
```

이런 방식을 자기 지도 학습이라고 볼 수 있다.

### 5.2 미세 조정

미세 조정은 이미 사전 학습된 모델을 특정 작업에 맞게 추가 학습하는 단계다.

예:

```text
리뷰 문장 -> 긍정/부정
질문 -> 정답
지시문 -> 원하는 응답
```

미세 조정의 대표 종류:

| 종류 | 설명 |
| --- | --- |
| 분류 미세 조정 | 텍스트를 보고 클래스 예측 |
| 지시 미세 조정 | 지시와 답변 쌍으로 학습 |

우리 과제의 미세 조정은 **NSMC 감성 분류**다.

### 꼭 암기

**사전 학습은 일반 언어 능력을 만드는 단계이고, 미세 조정은 특정 작업에 맞게 모델을 조정하는 단계다.**

## 6. 트랜스포머 구조

현대 LLM의 핵심 구조는 트랜스포머다.

트랜스포머의 핵심은 **self-attention**이다.

Self-attention은 문장 안의 각 토큰이 다른 토큰들을 얼마나 참고할지 계산하는 메커니즘이다.

예:

```text
문장: 나는 밥을 먹었다
```

`먹었다`라는 토큰은 `나는`, `밥을` 같은 앞 토큰들을 참고해야 의미가 자연스럽다.

Attention은 이런 참고 관계를 숫자로 계산한다.

### 원본 트랜스포머

원본 트랜스포머는 크게 두 부분으로 구성된다.

| 구성 | 역할 |
| --- | --- |
| Encoder | 입력 문장을 읽고 문맥 표현 생성 |
| Decoder | 출력 문장을 한 토큰씩 생성 |

번역 모델에서는 encoder가 원문을 읽고, decoder가 번역문을 생성한다.

---

## 7. GPT는 디코더 기반 모델이다

GPT는 원본 트랜스포머 전체를 쓰지 않고, **디코더 구조를 중심으로 만든 모델**이다.

GPT는 한 번에 전체 문장을 완성하는 것이 아니라, **왼쪽에서 오른쪽으로 한 토큰씩 생성**한다.

```text
이
-> 이 영화
-> 이 영화는
-> 이 영화는 정말
-> 이 영화는 정말 좋았다
```

이런 모델을 자기회귀 모델이라고 한다.

### 꼭 암기

**GPT는 decoder-only transformer이며, autoregressive 방식으로 다음 토큰을 하나씩 생성한다.**

---

## 8. BERT와 GPT의 차이

1장에서 중요한 비교가 하나 나온다.

BERT와 GPT는 둘 다 트랜스포머 기반이지만 목적이 다르다.

| 구분 | BERT | GPT |
| --- | --- | --- |
| 구조 | Encoder 중심 | Decoder 중심 |
| 방향 | 양방향 문맥 이해 | 왼쪽에서 오른쪽 생성 |
| 학습 | 가려진 단어 맞히기 | 다음 토큰 맞히기 |
| 강점 | 분류, 문장 이해 | 생성, 완성, 대화 |

쉽게 말하면:

```text
BERT: 빈칸 맞히기에 강함
GPT: 다음 말 이어 쓰기에 강함
```

우리 과제는 GPT 계열이므로 **다음 토큰 예측과 causal attention**이 중요하다.

---

## 9. 대규모 데이터셋이 중요한 이유

LLM은 대량의 텍스트에서 언어 패턴을 배운다.

데이터가 많고 다양할수록 모델은 더 많은 표현, 문법, 지식, 맥락을 접한다.

하지만 데이터가 크다고 항상 좋은 것은 아니다.

중요한 요소:

| 요소 | 설명 |
| --- | --- |
| 데이터 양 | 많은 문장을 볼수록 다양한 패턴 학습 |
| 데이터 품질 | 노이즈와 잘못된 정보가 많으면 성능 저하 |
| 데이터 다양성 | 여러 주제와 표현을 접해야 일반화 가능 |
| 토큰 수 | LLM 학습량을 나타내는 중요한 단위 |

### 꼭 암기

**LLM에서 데이터 크기는 보통 문자 수보다 token 수로 이야기한다.**

우리 과제에서는 거대한 웹 데이터 대신 NSMC 영화 리뷰 데이터를 사용한다.

## 10. GPT 구조 자세히 보기

GPT 구조는 크게 다음 흐름으로 볼 수 있다.

```text
텍스트
-> tokenizer
-> token IDs
-> token embedding + position embedding
-> transformer blocks
-> layer norm
-> linear output head
-> vocab logits
-> softmax
-> next token
```

각 부품의 역할:

| 부품 | 역할 |
| --- | --- |
| Tokenizer | 문장을 token ID로 변환 |
| Token embedding | token ID를 벡터로 변환 |
| Position embedding | token의 위치 정보를 추가 |
| Self-attention | 문맥 관계 계산 |
| Causal mask | 미래 token을 보지 못하게 막음 |
| FeedForward | 각 token 표현을 더 깊게 변환 |
| LayerNorm | 학습 안정화 |
| Linear head | hidden vector를 vocab 점수로 변환 |
| Softmax | 다음 token 확률 계산 |

### 꼭 암기

**GPT는 미래 토큰을 보면 안 된다. 그래서 causal mask가 필요하다.**

---

## 11. 왜 다음 토큰 예측만으로 똑똑해지는가

겉으로 보면 다음 토큰 예측은 단순해 보인다.

하지만 다음 토큰을 잘 맞히려면 많은 것을 알아야 한다.

예:

```text
입력: 파리는 프랑스의
정답: 수도
```

이것을 맞히려면 단순 문법뿐 아니라 지식도 필요하다.

또 다른 예:

```text
입력: 이 영화는 배우들의 연기가 훌륭해서 정말
정답: 좋았다
```

이것을 맞히려면 감정, 문맥, 표현을 이해해야 한다.

그래서 다음 토큰 예측을 대규모로 반복하면, 모델은 언어의 여러 패턴을 내부적으로 학습하게 된다.

### 꼭 암기

**다음 토큰 예측은 단순한 목표지만, 잘 수행하려면 문법·문맥·지식·추론 패턴이 필요하다.**

## 12. 사전 학습 모델과 파운데이션 모델

대규모 텍스트로 먼저 학습한 모델을 사전 학습 모델이라고 한다.

이 모델은 여러 작업에 적용될 기반이 되므로 파운데이션 모델이라고도 부른다.

```text
대량 텍스트로 사전 학습
-> 일반 언어 능력 획득
-> 특정 작업에 맞게 미세 조정
```

우리 과제에서는 거대한 파운데이션 모델을 만드는 것은 아니지만, 같은 원리를 작은 규모로 직접 구현한다.

## 13. 제로샷과 퓨샷

GPT 같은 모델은 사전 학습 이후, 어떤 작업은 별도 학습 없이도 수행할 수 있다.

| 개념 | 의미 |
| --- | --- |
| Zero-shot | 예시 없이 바로 작업 수행 |
| Few-shot | 몇 개의 예시를 보고 작업 수행 |

예:

```text
Zero-shot:
"다음 문장을 긍정/부정으로 분류해줘: 이 영화 정말 좋았다"

Few-shot:
"재밌다 -> 긍정"
"지루하다 -> 부정"
"이 영화 정말 좋았다 -> ?"
```

우리 과제의 mini GPT는 규모가 작기 때문에 이런 능력이 강하게 나타나지는 않지만, GPT 계열 모델이 왜 다양한 작업에 확장될 수 있는지 이해하는 데 중요하다.

## 16. 초보자용 비유로 다시 보기

LLM을 글쓰기 연습생이라고 생각해보자.

이 연습생은 수많은 문장을 보면서 이런 훈련을 반복한다.

```text
"오늘 점심은 김치찌개를"
-> "먹었다"
```

처음에는 단순히 다음 단어를 맞히는 것처럼 보인다.

하지만 잘 맞히려면 문장 흐름, 단어 의미, 문법, 상식, 감정까지 알아야 한다.

그래서 이 훈련을 엄청나게 많이 반복하면, 모델은 점점 자연스럽게 글을 이어 쓸 수 있게 된다.

GPT는 이런 글쓰기 연습생을 트랜스포머 구조로 만든 것이다.
